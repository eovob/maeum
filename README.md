# 마음결 · 오늘의 한 구절

기분/상황에 맞는 불교 경전 구절을 추천해주는 웹앱(PWA)입니다.
설치비, 개발비, 호스팅비 없이 완전히 무료로 만들고 사용할 수 있도록 설계했습니다.

## 지금 담긴 기능 (1단계)
- 기분/상황 10가지 중 선택 → 맞춤 구절 + 짧은 성찰 질문 추천
- 같은 구절이 바로 반복되지 않도록 최근 추천 기록 회피
- 마음에 든 구절은 하트로 "나의 서재"에 저장, 내 생각도 메모 가능
- 안드로이드 홈 화면에 앱처럼 설치 가능 (PWA), 오프라인에서도 동작
- 하단 탭에 "백과사전", "커뮤니티"는 다음 단계용으로 자리만 미리 만들어 두었습니다 (눌러도 "곧 만나요" 안내만 뜸)

## 폴더 구조
```
maeumgyeol/
├─ index.html      # 화면 구조
├─ style.css       # 디자인
├─ app.js          # 동작 로직 (추천, 저장, 화면전환)
├─ data.js         # 기분별 구절 데이터 (여기에 문구 추가/수정)
├─ manifest.json   # PWA 설정 (앱 이름, 아이콘 등)
├─ sw.js           # 오프라인 캐싱
└─ icons/          # 앱 아이콘
```

## 1. 내 컴퓨터에서 바로 확인하기
별도 설치 없이 폴더 안에서 아래 명령만 실행하면 됩니다 (파이썬이 설치되어 있으면 됩니다).
```
cd maeumgyeol
python3 -m http.server 8000
```
그다음 컴퓨터 브라우저에서 `http://localhost:8000` 접속.
(파일을 더블클릭해서 여는 방식은 서비스워커가 정상 동작하지 않을 수 있어요. 꼭 이렇게 로컬 서버로 열어주세요.)

## 2. 완전 무료로 인터넷에 올리기 (GitHub Pages)
1. github.com 에 무료 계정을 만듭니다.
2. 새 저장소(Repository)를 만들고, 이 `maeumgyeol` 폴더 안의 파일들을 전부 업로드합니다.
3. 저장소 Settings → Pages 메뉴에서 배포 브랜치를 `main`, 폴더를 `/ (root)`로 설정하고 저장합니다.
4. 몇 분 후 `https://내아이디.github.io/저장소이름/` 주소가 생성됩니다. 이 주소가 곧 내 앱 링크입니다.
(Netlify, Vercel, Cloudflare Pages도 동일하게 무료로 사용 가능합니다.)

## 3. 안드로이드 폰에 앱처럼 설치하기
1. 위에서 만든 주소를 안드로이드 폰의 **크롬(Chrome)** 브라우저로 엽니다.
2. 크롬 오른쪽 위 점 3개 메뉴(⋮) → **"홈 화면에 추가"** (또는 "앱 설치") 선택.
3. 홈 화면에 "마음결" 아이콘이 생기고, 이후로는 일반 앱처럼 실행됩니다. 인터넷이 없어도 이미 열어본 구절과 저장한 서재는 계속 볼 수 있어요.

## 4. 구절 내용 수정/추가하는 법
`data.js` 파일을 열어 `QUOTES` 배열에 아래 형식으로 항목을 추가하면 됩니다.
```js
{ mood: "peaceful", text: "구절 내용", source: "출처 표기", reflect: "생각해볼 질문" },
```
`mood` 값은 `MOODS` 배열에 정의된 id 중 하나를 사용하면 됩니다 (anxious, sad, angry, lonely, tired, afraid, regret, grateful, peaceful, confused).

## 다음 단계로 고려해볼 것들
- **나의 서재 강화**: 태그별 정렬, 검색, 내보내기(텍스트로 저장)
- **불교 백과사전**: 개념/인물/경전 용어를 카드 형태로 정리한 별도 메뉴 (지금 구조에 탭만 추가하면 됨)
- **커뮤니티**: 다른 사람과 구절/생각을 공유하려면 Firebase(무료 티어) 같은 백엔드가 필요합니다. 이용자가 많아지기 전까지는 무료 한도 안에서 충분히 운영 가능해요.

궁금한 점이나 다음 단계(백과사전, 서재 고도화, 커뮤니티) 진행하고 싶으시면 말씀해주세요!
